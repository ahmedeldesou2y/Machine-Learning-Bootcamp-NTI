# 🤖 Applied Machine Learning Bootcamp (NTI)

## 📌 Overview
This repository contains a structured and comprehensive track of Machine Learning models and pipelines. It is designed to go from raw data handling to building complex predictive and clustering models. Each module is self-contained with its own code, documentation, and best practices.

## 🗂️ Repository Structure (Table of Contents)

### Phase 1: Data Foundations
* **[01_Data_Preprocessing](./01_Data_Preprocessing):** Complete pipelines for data cleaning, handling missing values, encoding, and scaling using `ColumnTransformer`.

### Phase 2: Regression Models (Predictive Analysis)
* **[02_Linear_Regression](./02_Linear_Regression):** Fundamentals of continuous value prediction.
* **[03_Polynomial_Regression](./03_Polynomial_Regression):** Modeling non-linear relationships.

### Phase 3: Classification Models
* **[04_Logistic_Regression](./04_Logistic_Regression):** Binary and multiclass classification basics.
* **[05_KNN](./05_KNN):** K-Nearest Neighbors algorithm implementation.
* **[06_Naive_Bayes](./06_Naive_Bayes):** Probabilistic classification approach.

### Phase 4: Advanced & Ensemble Learning
* **[07_SVM](./07_SVM):** Support Vector Machines for robust classification.
* **[08_Decision_Tree](./08_Decision_Tree):** Tree-based modeling and interpretability.
* **[09_Ensemble_Learning](./09_Ensemble_Learning):** Combining models (Random Forests, Gradient Boosting) for higher accuracy.

### Phase 5: Unsupervised Learning
* **[10_Clustering](./10_Clustering):** Grouping unlabelled data using algorithms like K-Means.

## 🛠️ Technologies & Libraries Used
* **Python 3.x**
* **Data Manipulation:** `pandas`, `NumPy`
* **Machine Learning:** `scikit-learn`
* **Data Visualization:** `matplotlib`, `seaborn`
