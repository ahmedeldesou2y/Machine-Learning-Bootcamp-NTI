## 🗂️ Portfolio Architecture

The repository is logically structured to demonstrate progression from data preparation to advanced ensemble architectures:

### ⚙️ Phase 1: Data Engineering Foundations
* **[`01_Data_Preprocessing`](./01_Data_Preprocessing):** Developed an industry-standard template for automated data cleaning, handling missing values, and feature scaling using modular ML Pipelines.

### 📈 Phase 2: Regression Analytics & Forecasting
* **[`02_Linear_Regression`](./02_Linear_Regression):** *Car Price Estimation.* Engineered a multiple linear regression model to predict automobile market values.
* **[`03_Polynomial_Regression`](./03_Polynomial_Regression):** *Ice Cream Sales Forecasting.* Modeled non-linear business trends using polynomial feature transformation.

### 🩺 Phase 3: Classification & Clinical Diagnostics
* **[`04_Logistic_Regression`](./04_Logistic_Regression):** *Titanic Survival Analysis.* Handled severe missing data without dropping critical rows, using intelligent imputation.
* **[`05_KNN`](./05_KNN):** *Distance-Based Classification.* Implemented programmatic hyperparameter tuning to visualize and extract the optimal 'K' value.
* **[`06_Naive_Bayes`](./06_Naive_Bayes):** *Diabetes Prediction.* Applied probabilistic Gaussian models to a large-scale (100k+ records) medical dataset after rigorous outlier removal.
* **[`07_SVM`](./07_SVM):** *Breast Cancer Diagnosis.* Deployed Support Vector Machines with strict Feature Scaling, evaluated via comprehensive ROC curve analysis.
* **[`08_Decision_Tree`](./08_Decision_Tree):** *Interpretable Diagnostics.* Architected a rule-based, scale-invariant tree model, mapped with visual logic plots for clinical interpretation.

### 🚀 Phase 4: Advanced Machine Learning
* **[`09_Ensemble_Learning`](./09_Ensemble_Learning):** *Algorithmic Benchmarking.* Programmatically trained, evaluated, and visually ranked 8 distinct ensemble models (including Random Forest, AdaBoost, and XGBoost) to identify the highest-performing architecture for cancer diagnosis.
* **[`10_Clustering`](./10_Clustering):** *Customer Segmentation.* Transitioned to unsupervised learning, utilizing K-Means, Hierarchical Clustering, and the mathematical Elbow Method to group retail customers for targeted marketing.
